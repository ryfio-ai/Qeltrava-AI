# Qeltrava AI 2.0 — Page Architecture & Storytelling Rhythms

## Page Hierarchy & Composition

Every major route follows a structured narrative flow while maintaining a light theme visual palette.

### 1. Homepage (`/`)
1. **Header:** Sticky compact navigation (`ScrollTrigger` height transition).
2. **Hero:** Asymmetric headline + `QeltravaIntelligenceVisual.tsx` system canvas.
3. **Credibility Strip:** Engineering capabilities & client signals.
4. **Editorial Brand Statement:** SplitText/Line reveal.
5. **Capabilities:** 4 Asymmetric Engineering Pillars.
6. **Products Showcase:** MODLIQ & STAYSEAT narrative.
7. **Builder Lab Section (`#E3F2FD`):** Technical blueprint preview.
8. **Manufacturing Intelligence:** `IndustrialDataFlow.tsx` pipeline.
9. **Case Studies:** Real-world operational evidence.
10. **Human Accountability Philosophy:** Signature statement.
11. **Engineering Methodology:** 7-stage interactive timeline.
12. **Technology Directory & Final CTA (`#E3F2FD`).**
13. **Footer:** Light Theme (`#F8FAFC`).

### 2. Standalone Tools Hub (`/tools`)
- **Categories:** *Start with an Idea* (Build Lab, MVP Planner), *Validate the Idea* (AI Readiness), *Engineer the System* (Architecture Builder, API Planner, Database Planner).
- **Execution:** Productized interface with copy, JSON, and Markdown export tools.

### 3. Sector & Industry Subpages (`/industries/*`, `/services/*`, `/products/*`)
- Editorial intro, problem landscape, technology architecture, verified case study outcomes, and engineering consultation CTA.
